# Classificador de Nível de Herói

## Sobre o projeto
Projeto desenvolvido como desafio prático de lógica de programação em JavaScript. O objetivo é classificar o nível de um herói de acordo com sua quantidade de experiência (XP).

## Tecnologias utilizadas
- JavaScript
- Node.js
- Visual Studio Code

## Conceitos aplicados
- Variáveis
- Operadores relacionais e de atribuição
- Estrutura condicional (`if`, `else if`, `else`)
- Laço de repetição (`for`)
- Saída de dados com `console.log()`

## Como executar
1. Tenha o Node.js instalado.
2. Clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o comando no terminal: `node index.js`

## Funcionamento
O programa percorre diferentes quantidades de XP, classifica o herói conforme as faixas definidas e apresenta seu nível no terminal.

## Aprendizados
Este projeto foi uma oportunidade de praticar conceitos fundamentais de JavaScript, compreender o funcionamento dos laços de repetição e aplicar estruturas condicionais para resolver um problema lógico.
